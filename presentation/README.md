# Présentation Partitio

Présentation de soutenance construite avec [Slidev](https://sli.dev/).

```bash
npm install
npm run dev
```

La présentation s'ouvre ensuite dans le navigateur. Les champs `À compléter` dans `slides.md` sont les seuls éléments à personnaliser avant la soutenance (identité, équipe et captures d'écran).

Pour générer une version statique :

```bash
npm run build
```

Pour exporter un PDF (Chrome/Chromium requis) :

```bash
npm run export
```
